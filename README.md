# 🌾 Farmer Direct Marketplace

UI/UX project designed during PRAGYATHA’24 Hackathon at Malnad College of Engineering.

## 🚀 Problem
Farmers face:
- Dependency on intermediaries
- Reduced profit margins
- Lack of direct consumer access

## 💡 Solution
A direct farmer-to-consumer marketplace platform that eliminates middlemen.

## ✨ Features
- Direct product listing by farmers
- Transparent pricing
- Profit & loss tracking dashboard
- Simple and intuitive UI/UX

## 🔄 User Flow
Farmer:
Login → Add Product → Set Price → Sell

Buyer:
Login → Browse → Purchase->Profit and loss Analysis

## 🛠 Tools Used
- Figma (UI/UX Design)
